# Haspataal Nurse Manual

## Overview
This manual is for nurses using Haspataal HMS.

## Responsibilities
- Manage IPD admissions
- Administer medications
- Update vitals
- Coordinate with doctors
- Handle discharge process

## Key Workflows

### IPD Admission
1. Search patient
2. Select ward and bed
3. Complete admission form
4. Assign doctor

### Medication Administration
1. View medication schedule
2. Record administration
3. Document any adverse reactions

### Discharge
1. Verify discharge summary
2. Ensure all bills are settled
3. Update bed status
4. Hand over to family
