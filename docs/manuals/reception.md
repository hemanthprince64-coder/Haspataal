# Haspataal Reception Manual

## Overview
This manual is for reception staff using Haspataal HMS.

## Responsibilities
- Book appointments
- Register patients
- Handle billing inquiries
- Manage queue
- Process payments

## Key Workflows

### Patient Registration
1. Click New Patient
2. Enter demographics
3. Select insurance if applicable
4. Save record

### Appointment Booking
1. Select doctor and specialty
2. Choose date and time
3. Enter patient details
4. Confirm booking
5. Send confirmation (WhatsApp/SMS)

### Payment Collection
1. Navigate to Billing
2. Select invoice
3. Choose payment method
4. Record payment
5. Print receipt
