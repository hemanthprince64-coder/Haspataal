# Haspataal Doctor Manual

## Overview
This manual is for doctors using Haspataal HMS.

## Responsibilities
- Manage appointments
- Conduct consultations
- Write prescriptions
- Review lab results
- Update patient records

## Key Workflows

### Appointment Management
1. View today's appointments
2. Start consultation
3. Add diagnosis and notes
4. Prescribe medicines or order tests
5. Complete consultation

### Prescription
1. Select patient
2. Add medicine, dosage, duration
3. Submit prescription
4. Patient can view and print

### Lab Results
1. Navigate to Lab Results
2. Review incoming results
3. Add interpretation
4. Mark as reviewed
