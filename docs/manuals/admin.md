# Haspataal Admin Manual

## Overview
This manual is for Super Admins managing the Haspataal platform.

## Responsibilities
- Approve hospital onboarding requests
- Verify doctor credentials
- Manage platform-wide settings
- Review audit logs and compliance reports
- Handle escalation alerts

## Key Workflows

### Hospital Approval
1. Log in to Admin Panel
2. Navigate to Hospitals → Pending
3. Review uploaded documents
4. Click Approve
5. Set commission percentage and payout cycle

### Doctor Verification
1. Navigate to Doctors → Pending
2. Verify medical registration number
3. Approve or reject

### Billing Configuration
1. Navigate to Billing → Profiles
2. Set GST applicability
3. Configure payment gateways
4. Set invoice layout

## Security
- Use strong passwords
- Enable 2FA if available
- Review audit logs weekly
- Never share credentials
