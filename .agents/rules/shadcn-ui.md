## shadcn-ui

Use this skill when installing, building, or customizing UI components using shadcn/ui. Follow [shadcn-ui SKILL.md](file:///C:/Users/heman/.gemini/config/skills/shadcn-ui/SKILL.md).

Rules:
- Reuse and customize shadcn/ui components by placing them directly in the codebase (e.g. `components/ui/`).
- Use the `cn()` utility to merge and override Tailwind classes safely.
- Follow keyboard navigation and screen reader accessibility guidelines from Radix UI.
- Use `class-variance-authority` (cva) for defining component variants.
